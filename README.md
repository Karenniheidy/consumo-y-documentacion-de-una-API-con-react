# Sistema TechStock - Consumo y Documentación de una API con React y Express

## Descripción del proyecto
**TechStock** es una aplicación web desarrollada como parte del proceso de formación en el programa de Análisis y Desarrollo de Software (ADSO) del SENA. El sistema implementa una arquitectura desacoplada que integra una interfaz de usuario interactiva construida en **React (Vite)** con un servidor backend independiente en **Node.js y Express**, permitiendo la gestión asíncrona de inventarios, categorías y transacciones comerciales mediante solicitudes HTTP (GET y POST)

---

## Tecnologías utilizadas
* **Frontend:** React, Vite, JavaScript (ES6+), HTML5, CSS3.
* **Backend:** Node.js, Express, CORS.
* **Herramientas de desarrollo:** Visual Studio Code, Git Bash, Postman.
